统计口径与操作边界

Git 为逻辑文件字节，合计包含未配置仓库的残留缓存；不含 Gitea 源仓库。队列合计包含活动、归档和隔离文件；每个文件至少预留 64 KiB，并非实际磁盘占用。达到阈值只提示，不自动删除、重试或提高预算。采样锁忙时保留旧值；最近超限是历史记录，不代表当前仍超限，也不覆盖进程被内核直接终止的情况。

统计口径与操作边界

核对仅说明当时的数据与引用状态，不结案原恢复、不解除清理屏障、不切换版本。当前指向目标不证明过去的回滚成功。核对后正常发布也会改变引用；页面不会重新读取全部对象。

恢复审计容量与归档

独立定时缓存 · 不在页面中遍历归档

统计口径与操作边界

条数按实际位置分别计数，处理中同一审计可同时出现在多个位置。逻辑大小为文件长度，磁盘占用含目录分配块；归档逻辑大小为压缩包长度。默认归档规划为保留最近 20 条、完成 30 天、单轮 100 条；不是上次自定义参数。实际操作结果单独记录，容量要到下一轮采样才更新。

待清理暂存不为零时先核验归档；归档默认只预览，坏记录和未结案证据不会被强制移走。
