# 验证范围

验证分为普通回归、隔离部署和已有服务器验收。历史结果见[归档](history/README.md)；下列记录只覆盖本次变更，不将旧测试计数合并为新结论。

## 文档与初始化保护

- 使用指南区分空仓库首次提交与后续更新；测试直接执行文档中的两段命令。
- 准备脚本在创建私有材料前拒绝已有配置或非空数据。初始化在调用 Docker/API 前检查首次准备标记，并独占创建初始化记录。
- 已有、并发和中断状态均受保护；程序没有强制覆盖开关。旧版部署没有准备标记，也不能重新初始化。
- 日常发布、重试、恢复和审计示例统一使用宿主机 CLI；容器内部入口用于服务启动、配置生成和隔离验证。

## 2026-11-08 验证结果

- 230 项 Python 回归在无网络、只读根目录的 Linux 容器中通过；22 项界面测试和 Ruff 检查通过。
- 独立 Linux aarch64 / Docker 28.5.2 环境完成首次准备与初始化、CLI 新增和重复接入。两个空仓库都执行使用指南中的首次提交与后续更新命令，目标任务均为 published。
- 重复准备和初始化被拒绝，私有配置与凭据哈希保持一致；接入重复执行保留仓库 ID、单个只读 Key/Hook，并不重启 Worker。
- 中文、空格、加号和百分号路径、图片/附件字节、Range、匿名管理跳转和认证后入口读取通过。入口使用测试 CA，不覆盖公共 DNS/ACME。
- Markdown 链接与锚点、日常 CLI 示例、空仓库和已有分支更新流程有回归检查。历史记录保留在归档中，当前说明不再引用验收仓库或本机工具授权过程。

## 已有服务器验收

- 更新前保全应用与私有配置，核对公开源码基线。部署只替换脚本和文档，九个容器保持原 ID 且健康，八个定时器运行；没有重启业务容器。
- 在旧版已运行部署上直接执行两个初始化脚本，均在修改前拒绝，环境变量缺失也不绕过检查。私有配置、账号凭据和证书哈希不变。
- 统一 CLI 的 validate、doctor、仓库列表、状态过滤和链接生成通过。专用仓库真实 SSH Push、图片回滚保护、历史附件、字节与 Range 检查通过。
- Gitea、OC、Traefik 与 Info 的匿名跳转和认证后读取正常，Info 主机快照新鲜。临时测试身份已撤销，独立测试容器已清理。

公开源码检查排除了生产域名、地址、私有配置、凭据与运行截图。源码哈希与服务器一致；证据保留在私有位置。
