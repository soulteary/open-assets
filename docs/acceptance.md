# 验证范围

新服务器 Traefik 示例、社区上手文档和网页公开分享的独立验证见[2026-11-08 验收记录](history/2026-11-08-community-onboarding.md)，包含权限边界与未覆盖范围。

本次记录覆盖结案拒绝提醒的人工确认 CLI、独立审计和 Info 标灰/失效提醒。此前历史提醒、诊断看板与发布流程的结果见[历史记录](history/README.md)。

## 隔离验证（2026-11-08）

- 265 项 Python 测试在无网络、只读源码、256 MiB 内存限制的独立 Linux 容器中通过；33 项界面测试、Ruff 和文档链接检查通过。
- 默认预览不创建确认文件；带本次证据令牌才确认。错误/过期令牌、旧尝试、未完成记录、异常链接、证据不可读、锁忙及容量上限均不能强制确认。
- 相同证据与原因重复执行复用确认；原拒绝和恢复报告保持原字节。原因及目标关联摘要不进入 Info 快照。
- 配置、清单、原报告、引用、最近尝试变化后确认失效；新结案尝试恢复提醒。确认失效不能被原有“无需结案”的历史分类掩盖。
- 新建审核目录同步父目录，父目录同步失败不返回确认成功。中断或指针发布失败保留未生效审核记录，不将其显示为已处理；写入期间证据变化也不发布确认指针。
- 人工确认审计独立于 Publisher 可写挂载，拒绝不安全的父目录权限。人工确认只影响对应拒绝提醒，不结案不确定恢复、不消除其他核对问题、不切换版本或解除屏障。Info 仅读取固定指针和有限文件，不遍历确认历史；页面不执行确认操作。

## 已有服务器验收

- 部署前核对源码并备份应用、Publisher 和 Info。仅重建 Info，其他容器保持原 ID；九个容器健康、九个定时器运行。
- 在独立临时测试部署目录中调用已安装的宿主机脚本，完成预览、显式确认、重复执行、证据变更拒绝、重新审核及新尝试失效。确认前后原始拒绝文件不变，临时目录已清理。
- 生产中的既有拒绝记录保持待审核，没有代填原因或执行人工确认。原始报告、既有审计、published 和 current，以及私有配置、凭据和证书保持不变。
- 浏览器确认线上提示包含查询拒绝审计、填写原因、默认预览和显式确认的说明。灰色/失效展示以真实格式的隔离文件与界面测试验证。
- 既有 doctor、日常 CLI、公开图片附件字节/Range、受保护管理入口的匿名跳转和认证读取正常。

本功能记录人工审核，不执行对象内容校验，不替恢复结案；证据绑定不等于持续监控所有外部写入，也不是防宿主机管理员篡改的存储。公开源码检查排除生产域名、地址、私有状态、确认原因和运行截图。原始验收证据保存在私有位置。
