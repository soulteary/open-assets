## 保留的范围及后续工作

单机、单 Worker、本地 POSIX、跨系统无联合事务、可信管理员和外部独占写入前提继续适用。这些属于部署协议，没有通过本轮修复改造成分布式或多租户产品。

对象清理仍保留 45 秒、500 次请求、50,000 次列表条目预算（包含重复列表）。本轮解决单版本超过删除预算不能前进的问题，没有实现跨轮的全仓库扫描游标。超过列表预算仍会明确停止，需要分仓、调整保留规模或后续设计独立的大规模维护方案；不要宣称任意规模均可持续清理。单个对象若超过字节预算，也需提高预算后才能删除。

网页上传仍与 Git 生命周期分离：公开桶、路由和日常 IAM 身份按现有网页分享文档配置。本轮没有实现新的统一资产模型、幂等分享配置 CLI 或多人角色管理。浏览器 UI、真实 DNS/ACME、干净机器整套恢复、真实存储吞吐和长期大规模压测也未在本轮环境中执行。发布稳定版本时应依据 CI、隔离部署及恢复演练的实际结果声明支持范围。

## 升级说明

更新源码并重建 Publisher/Webhook 与 Info；对象清理器使用重建后的镜像。保持原有 enabled、exclusive_writer、IAM 和 --apply 门槛。旧 deleting 收据格式可继续使用，无需删除历史状态。启用实际删除前重新预览，并核对单轮对象/字节上限；新版可能开始回收以前因整版过大而一直被跳过的过期版本。

status 的前四列不变，资源限额原因若存在仍保留，末尾追加 images 字段。解析整行或依赖固定列数的外部脚本应同步调整。

backup.sh 现在需要完整快照的入口与 ACME 路径，缺少时会失败，不再生成看似完整但漏入口状态的归档。演练解包会拒绝既有目标目录及越界链接，且不恢复服务或 UID/GID；完整恢复步骤见[运维说明](operations.md#完整快照与恢复演练)。
