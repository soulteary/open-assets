# Open Assets v0.10.1

Release date: 2026-11-26 (Asia/Shanghai).

## Changes

- Pin the officially accepted OtterIO/OC release pair and immutable image digests.
- Pin Stargate 1.8.1 and Certs Maker 3.8.3; record verified Linux amd64/arm64 certificate-tool archive hashes.
- Include the Rust reqwest trust-root, SVG/XML parsing, HMAC API and dependency updates already merged since v0.10.0.
- Align the Rust CLI package version and lockfile with v0.10.1.

This project builds its own Rust webhook service; it does not consume the separate webhook repository binary. No external webhook image is added. This remains a source release with the existing local Docker build workflow; no new prebuilt Open Assets image or npm package is claimed.

## Upgrade and rollback

Back up private configuration, credentials, database/object state, publication records and exact previous images before maintenance. Compare the public .env.example with the private .env; update only the selected image and certificate-tool pins. Do not rerun initialization over an existing deployment or replace the complete private .env. Rebuild the Open Assets image from this tag. Retain previous images and compatible complete snapshots for rollback; do not relax authentication or TLS verification. Existing authentication mode and private-CA boundaries remain unchanged. See docs/upgrade.md and docs/operations.md.
