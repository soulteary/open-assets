基线为 `e294206605c8aeec9703bf87029cd7261cddb839`，叠加本次社区文档、Traefik 模板及端到端脚本修改。没有连接或修改已有部署服务器。

## 环境与步骤

使用专用 Linux aarch64 虚拟机中的独立 Docker-in-Docker，Docker Engine 28.5.2、Compose 2.40.3、宿主脚本 Python 3.12.16。没有向个人电脑发布应用端口，也没有挂载宿主 Docker socket。仅复制公开源码，全部账号、证书和对象均在测试环境生成。

首次拉取镜像遇到连接中断，重试固定镜像后，从已准备的私有测试配置继续构建与初始化，没有删除初始化标记或放宽保护。随后运行 fresh-stack 的发布验证和 community.py 附加验收。复现入口见[端到端测试说明](../../tests/e2e/README.md#新入口与网页分享配置)。

## 结果

- 首次初始化、重复准备/初始化拒绝、CLI 新建仓库与重复执行、前缀冲突拒绝通过。
- 两个空仓库各完成首次提交与后续 Push，四个任务全部 published；图片、版本附件、特殊路径与 Range 逐字节校验通过。
- 新服务器 Traefik 模板使用 UID 20003、只读根文件系统和指定外部网络启动。静态配置未修改，Docker healthcheck 为 healthy；HTTP 跳转至公开 HTTPS 默认端口，未跳到内部 8443。
- 匿名访问存储管理、Git 和 Traefik 入口均进入认证页面。
- 直接执行网页分享文档中的建桶、公开策略与路由代码块。重复建桶与重复生成路由被拒绝；原 attachments 策略保持不变。
- 使用 OC API 登录、创建上传并上传测试文件；不带管理 Cookie 的 GET、HEAD、Range 和中文、空格、加号、百分号路径读取通过。
- 同时通过公开入口和直接访问测试 S3 检查权限。匿名列桶、读取 private 前缀、写入和删除均被拒绝；拒绝后公开对象字节不变。
- OC 缺少 CSRF Token 的退出请求被拒绝；合法退出后原会话访问 API 返回 401。
- 移出公开路由后文件返回 404，恢复路由后读取成功。Git 任务、清单、版本副本、current 与 published 保持不变；正常更新的 Worker 心跳不属于内容不变性比较。

补充明确了生成路由的读取权限，避免管理员严格 umask 让非 root 网关读不到配置。目录权限与部署文档一致，ACME 状态为 0600。
