# 验证范围

当前记录覆盖 doctor 诊断改进。此前初始化、首次发布和其他功能的结果见[历史记录](README.md)。

## 隔离验证（2026-11-08）

- 237 项 Python 测试在无网络、只读根目录、256 MiB 内存限制的独立 Linux 容器中通过。最后调整后，21 项诊断、CLI 和文档测试再次通过；22 项界面测试及 Ruff 检查通过。
- 覆盖必需任务关闭、可选任务关闭、已关闭任务保留的失败结果、服务超时/信号终止、尚未执行、条件跳过、超期未执行、正在执行和状态不可读取。
- 使用真实格式的四类缓存文件运行完整 doctor CLI，核对正常/异常退出码。可选任务关闭不影响通过；主机快照新鲜而对象样本过期时仍返回待处理。
- 覆盖缓存缺失、配置范围变化后的失效、采集失败/未完成、时钟超前和采样过期；测试禁止目录扫描、S3 调用和诊断过程写入。
- 故障场景在隔离环境构造，没有停止线上 timer、制造线上任务失败或篡改线上缓存。

## 已有服务器验收

- 部署前核对源码基线并备份应用与私有配置；只替换宿主机诊断代码和文档，未更换镜像或重启业务容器。
- 五个必需与三个可选 timer 的真实状态、最近执行结果正常。本地版本、对象、审计逐仓库样本和全局 Git/队列样本均在各自时限内。
- CLI 的 JSON 与文本输出通过；配置校验、现有仓库查询和管理入口读取正常。
- 九个容器保持原 ID 且健康；私有配置、凭据、证书保持不变，没有开启清理策略或补跑修复/删除任务。

检查不覆盖外部 DNS、备份恢复、业务对象逐个校验或长期稳定性。systemd 状态只代表本次开机可读取的执行记录，不能替代完整历史日志。公开源码排除生产域名、地址、私有材料和验收原始输出；证据保存在私有位置。
