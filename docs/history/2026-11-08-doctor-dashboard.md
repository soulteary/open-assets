# 验证范围

本次记录覆盖 Info 部署诊断页签及独立诊断缓存。此前 doctor CLI、初始化与发布的结果见[历史记录](README.md)。

## 隔离验证（2026-11-08）

- 244 项 Python 测试在无网络、只读源码、256 MiB 内存限制的独立 Linux 容器中通过；26 项界面测试与 Ruff 检查通过。
- 诊断采集按间隔执行，普通缓存读取不调用 doctor、命令或目录扫描。连续 HTTP 请求只返回已保存的快照。
- 覆盖检查结果有待处理但采集成功、采集失败保留旧报告、中断状态可见及后续恢复、缓存过期、时钟超前、文件缺失/损坏/超限、配置范围变化、字段过滤和采集锁。
- 界面覆盖必需/可选分组、缓存年龄与阈值、旧结果和失败提示、刷新失败后取消通过结论、文本安全渲染，以及页签鼠标/键盘切换。
- 使用现有应用镜像和相同依赖构建无网络候选镜像，没有更新基础镜像或软件版本。

## 已有服务器验收

- 部署前核对源码基线并备份应用与 Info 状态。仅重建 Info；其余容器保持原 ID，九个容器健康。
- 独立诊断定时器安装后，九个 timer 均运行。报告包含五个必需、三个可选任务及 13 份缓存样本；诊断采集正常、采样时检查通过。
- 连续五次读取 Info API，诊断缓存字节保持不变。配置校验、现有 doctor 和其他日常 CLI 通过。
- 浏览器确认诊断页签的分组、最近执行结果、退出码、年龄与阈值、排查提示。刷新后保持页签，使用同一份诊断采样；没有通过浏览器触发检查。
- 图片和附件字节、Range、管理入口匿名跳转及认证后读取通过。Stargate 保护和路由未改动。
- 私有配置、凭据和证书哈希不变，没有补跑修复或清理、开启删除策略或修改现有仓库。

线上未人为停止任务或篡改缓存来制造故障；异常场景在隔离测试中验证。诊断是采样时结果，不验证全部业务内容或外部备份，也不代表持续可用性。公开源码检查排除生产域名、地址、私有状态及验收原始输出；运行证据不提交仓库。
